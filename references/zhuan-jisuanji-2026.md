## 一、硬性报名条件（缺一即出局）

1. 体检合格（依《普通高等学校招生体检工作指导意见》）
2. **只接收高考理科考生**（不分文理省份须高考选考**物理**）
3. **第一外语为英语**
4. **各学期已修读课程首次考核成绩须全部合格**（不得有缓考、缺考）**且 GPA 排名在原专业前 30%**
5. 无违纪行为（不含已解除处分者）
6. 2025级需2025年入学 / 2024级需2024年入学
7. 2024级转入必须降级至2025级；2025级（含2026级）按所在年级转入，**可自愿申请降级**

## 二、名额（2026年度）

总接收 **97 人**：
- 2025级 72 人：计算机科学与技术 47 / 网络空间安全 15 / 物联网工程 10
- 2024级 25 人：计科 16 / 网安 5 / 物联网 4（必须降级）

对比：车辆工程（汽车工程学院）2026 名额 44 人。

## 三、考核方式：笔试70% + 面试30%

| 项目 | 内容 |
|------|------|
| 笔试科目 | **《微积分AI》**，100分（⚠️ 用户现学的是**微积分BⅠ**，AI版更深更广）|
| 进面条件 | 笔试原始成绩 **≥60**，**且**排名在申请转入专业接收计划 **前130%** |
| 考试范围 | **以现有大学所学知识为主** |
| 面试 | 100分，考核：计算机软件技术知识/应用/前沿热点了解程度、计算机类课程学习情况及软件使用经历、思政修养与品德、学习成绩/奖励/社会实践、人文素养 |
| 计分 | `考核成绩 =（笔试原始成绩×70% + 面试成绩×30%）× 志愿批次比例` |
| 志愿系数 | 一志愿 **100%** / 二志愿 **90%** / 三志愿 **80%** → **必须放第一志愿** |
| 同分 | 参考笔试原始成绩，高者在前 |
| 录取 | 按考核成绩排序 → 拟录取(100%) / 递补(30%) / 不录取，公示后上报学校投档 |

## 四、唐敖庆试验班特例
- 唐敖庆班计算机专业学生申请转出：学院不作限制
- 其他学院唐敖庆班转入唐敖庆班计算机：正常参加笔试+面试
- 其他学院唐敖庆班转入计算机类（非唐敖庆班）：**免笔试**，直接面试，不占笔试排名名额

## 五、转专业后安排
- **一个月适应期**：学籍异动后1个月内可在网上办事大厅申请放弃转回原专业，超期不受理
- 学分认定：按《吉林大学本科学生转专业工作管理办法》（校发〔2024〕201号）**第五章**执行
- 组织：学院工作组组长杨博；监督组组长宫皓宇

## 六、给用户的实操判断（2026级交通学院 → 计算机）

| 维度 | 计算机 | 车辆工程 |
|------|--------|---------|
| GPA 门槛 | **原专业前30%**（交运类253人→前~76名）| ≥3.0 |
| 笔试 | 微积分AI（70%）| 数学50%（微积分BI+高中）|
| 面试权重 | 30% | 50% |
| 名额 | 97 | 44 |
| 首次考核 | 全部合格（补考无效）| 同 |

**双线可行**：微积分与 GPA 是两条通道的**共同战场**，大一先保 GPA+零挂科，大一下按绩点排名决定主攻（前30%→冲CS，否则→车辆）；分流（汽车运用工程，绩点≥3.3）为最终保底。

**待核实（第一道门槛）**：用户高考是否理科/选考物理——不满足则计算机通道直接关闭。

## 七、时间线（按2026年校历推演到2027年）
- 大一上：保GPA（前30%）、零挂科、启编程自学、建GitHub学习仓库
- 寒假：补微积分AI超纲部分（多元微积分/级数/更深证明题）+ 做1-2个可展示项目
- 大一下开学：填报志愿（**第一志愿**）→ 学院组织微积分AI笔试 → 面试 → 公示
- 学籍异动后1个月内：适应期
