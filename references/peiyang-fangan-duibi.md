## 二、关键结论：核心课「前半段全重合，后半段分叉」

**三专业通用（大一~大二上）**：工程制图/图学 → 理论力学 → 材料力学 → 机械原理 → 机械设计 → 电工学 → 工程材料

**分叉（大二下起）**
| 专业 | 特色课 |
|------|--------|
| 交通运输 | 汽车构造、汽车运用工程、汽车检测诊断、汽车可靠性维修、物流/交通规划 |
| **车辆工程** | **汽车理论、汽车与车身构造、车身设计、汽车造型**、流体力学、工程热力学、控制工程基础、制造工艺学、工业设计基础 |
| 机械工程 | 机械制造技术基础、机电传动控制、液压与气压传动、测试技术、数控/机器人 |

→ **转专业 = 同机械大类内平级切换，学分认定顺畅、无补课压力**；但车辆更偏工科（多了工程热力学/流体力学/控制），**大学物理是硬前置**（用户大一上未开放，需大一下补）
→ 吉大车辆招牌 = **车身设计方向**（车身设计/汽车造型/工业设计基础），对接吉速车队

## 三、车辆工程模块学分结构（2026版）

- 公共基础课 75.5；专业教育课 36（核心28 + 拓展8）；通识 12（核心10-12 + 非核心0-2）；公共基础实践 34.5；课外培养 8
- 实践：工程训练、机械设计综合实践、**生产实习、专业认识实习**、工业设计创新实践、毕业设计
- 机械工程：公共基础64.5 / 专业教育47.5（核心37.5+拓展10）/ 实践36.5；含5个方向（机械工程/工程力学/工业工程/智能制造/卓越班）

### 学习场地（南岭）
- **"一站式"学生社区**：南岭 = **学生十二公寓、十三公寓**（自习室/活动室/口语角/学术沙龙，下楼即达）
- 图书馆 = **工学馆**（吉大共8馆）；座位预约 `libseat.jlu.edu.cn` 或「智慧吉大」企业微信
- 教学楼自习：看门口智慧屏找空闲教室

### 教学日历与考试
- **考试周：2027年1月4日–15日**（两周）；本科生院公布公共基础课时间，学院排专业课
- **大一年级考试时间 = 每日上午 9:00–11:00，每天只安排一门正课**
- 部分课程**结课即考试**，不能只靠考试周突击

### 学分/绩点规则
- 理论课 **16学时=1学分**、实验课 **34学时=1学分**、实践课原则上 **1周=1学分**
- 综合成绩 **60分及以上** 才修得学分
- **学年奖学金 = 课程加权平均成绩**；**推荐免试研究生（保研）= 平均学分绩点（GPA）**
- 成绩表示：百分比制 / 绩点制 / 等级制（三者有官方换算表）

### 选课规则补充
- 每学期 **正选 + 退补选** 两阶段；本科生院 **每年6月、12月** 发下学期选课通知，**每年3月、9月** 发本学期退补选通知
- **新生第一学期选课与老生9月退补选同批次**（用户 9/28-29 那轮可换课）
- 预置课程**原则上不可退**；**不可跨校区选课**；选课系统关闭前登录 `iedu.jlu.edu.cn`「我的教学」→「我的课表」确认无漏选错选
- 所有未通过课程**都会记录在成绩单上**
- 培养方案进程表规定各选修模块最低学分，**毕业前必须修满各模块**，否则无法按时毕业
- 教学日历/教务系统：`https://iedu.jlu.edu.cn`；选课：`https://icourses.jlu.edu.cn`
