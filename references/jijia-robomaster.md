## 三、RoboMaster 赛制

**赛事分级**：RMUC（超级对抗赛，主赛事，7v7）> RMUL（高校联盟赛，门槛低，多数队伍起步赛事）> RMUA（高校人工智能挑战赛）/ RMU（青年赛/通信协议）。

**RMUC 模式**：每队 7 台（英雄1/工程1/步兵3/哨兵1/空中1）对抗，打掉对方**基地**即胜；有资源岛、环形高地、飞坡；步兵上高地抽弹丸、工程去资源岛采矿＝经济战；哨兵全自动。

**参赛要求**：在校本科生、以高校为单位组队；报名后要过 **五关技术评审**（2026 版）：赛季规划（812041）→ 规则测评（812042）→ 中期进度文档（812044）→ 裁判系统考核（812043）→ 完整形态考核（812045）→ 赛季总结（814542）。机器人不合规（超尺寸/超功率/用禁件）直接取消资格；**硬指标在《机器人制作规范手册》里，不在规则手册里**——判断零基础要学多久看这本（10.6MB）。

**规则版本滚动**：2026 规则手册走 V1.0.0（2025-10-21）→ V2.2.0（2026-08-07）一路修订；2027 正式手册赛季前才发（2026-09 时点只有《2027 高校系列赛规则变更前瞻手册》19 页）。

## 四、规则中心 API 取数（页面是 Vue 空壳，读 DOM 拿不到东西）

正文和附件全靠 JS 拉；`browser_snapshot` 只返回目录标题，正文是 `<p><br></p>`。直接打接口：

```python
# 1) 目录树 —— 必须 POST（GET 返 405）
POST https://bbs.robomaster.com/developers-server/rest/wiki/info/20204847
     body: {}   # Content-Type: application/json
     -> data.treeRoot            # ⚠️ 是 treeRoot/children，不是 childs/nodes
                                 # 每个节点: title + postsId

# 2) 单页详情 + 附件
POST https://bbs.robomaster.com/developers-server/rest/posts/info/<postsId>
     body: {}
     -> data.fileItems[]  { id, name, src }        # 下载直链
        data.attachments[]                            # 部分页面用这个字段
```

遍历树取全部附件：递归收集 `children` 为空的叶节点，对每个 `postsId` 打第二个接口。实测 **96 个叶节点、约 30 个带附件、合计 300+ 文件**。

浏览器内可同源 `fetch`（带 cookie）；纯脚本 POST + `User-Agent` 即可，无需登录。

### ⚠️ 下载必踩：URL 含空格和中文

OSS 直链形如
`https://hz-rm-bbs-web-prod.oss-cn-hangzhou.aliyuncs.com/<hash>/RoboMaster 2027 高校系列赛规则变更前瞻手册（20260909）.pdf`

```python
import urllib.parse, urllib.request          # ⚠️ 两者都要显式 import
safe = urllib.parse.quote(url, safe=":/%?&=#[]@!$'()*+,;~-_. ")

fn   = urllib.parse.unquote(url.rsplit("/", 1)[-1])   # 落地文件名用 unquote 还原
```

校验：PDF 头 `%PDF`（hex `25504446`）、xlsx/docx 头 `PK`（hex `504B0304`）。页面里的 `image.png` 是正文插图不是文档，别当垃圾下。

## 六、2027 赛季重大变更（源自《2027 高校系列赛规则变更前瞻手册》，2026-09-09）

**明年是结构性大改版，全是框架级变动：**

| 类别 | 变更 |
|---|---|
| 机器人系统 | ① **英雄 + 工程 → 合并为「重装机器人」** ② 空中机器人部署/使用/功能**重构** ③ 自定义控制器 + 自定义客户端 → 合并「**自定义终端**」 |
| 场地 | ① **飞坡 → 隧道** ② 操作间布置调整 ③ 增设**制高点 / 机库放置区 / 工作台** ④ 移除飞行区和无线充电装置放置区 |

**阵容：7 类 8 台 → 6 类 7 台**（重装1/步兵**2**/空中+机库1/哨兵1/飞镖1/雷达1）；最低上场阵容由「除雷达飞镖外至少4台」放宽为**至少3台**。

**重装机器人**（新核心机种）：装配**能量单元**换团队增益，装配三级解锁 42mm 发射机构。血量开局 400 → 三级 600；三级/四级射击初速上限 16.5 m/s、热量上限 300、冷却 100。解锁条件三选一：三级装配 / 比赛满 5 分钟 / 落后提前。**发射机构开局放资源区工作台不装车**，七分钟比赛阶段才能安装（RMUL 无装配任务，开局即解锁）。主机体 ≤30V 且须与发射机构电气隔离。重量 36kg（不含机构）/ 41kg（含）。

**空中机器人 + 机库**（彻底重做）：改**全自动**、**禁止装发射机构**；靠**撞击**对方前哨站/基地装甲造成伤害，且能**主动迎击拦截对方飞镖与弹丸弹道**；悬停取信息回机库再供给雷达。硬要求：悬停 ≥10s、**全包围桨叶保护罩**（桨叶机体不得外露）、**柔性桨叶**、紧急停桨遥控器 + **配安全员**。机库在战场中央分红蓝放置区，装 4 台，起飞限竖直法线 15° 内。

**场地机制（新）**：制高点（三级台阶可攀越，占点 = **50% 防御增益** + 非远程兑换发弹量）；隧道（**跨越** 25% 防御/30s；**穿越**含内部卡 = **1.5 倍热量冷却/120s**；须 3 秒内按序检完且途中不碰其他交互卡）。

**自定义终端**：图传 UDP、比赛数据 **MQTT + ProtoBuf**；可发指令含赛前选性能体系、赛中兑换发弹量、**干预哨兵行动**；**严禁任何无线收发装置**；操作间内可 RJ45 有线接入赛事引擎，终端之间可互连。

### 报名真实门槛（2026 版，用户最该知道的）

**报名 ≠ 能参赛**，须过考核链：赛季规划文档 → **规则测评考试（不过不能参赛）** → 裁判系统考核 → 中期进度文档 → 完整形态考核（交真机+文档）→ 赛季总结 → 飞手资格考核。**十六强队伍必须开源「战队传承分析」**（论坛上同济 SuperPower、华南虎等都有）。

操作手**只能由除指导老师外**的本赛季场地人员担任；飞手需单独考证并佩戴标识。
