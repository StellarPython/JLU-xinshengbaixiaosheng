# 吉大党内文书写法（入党申请书 / 思想汇报 / 转正申请）

> 用户 2026-09 入学后即需提交入党申请书 → 后续每季度思想汇报、转正申请同一套 house rules。
> 格式原件：`吉林大学相关文件\入党\入党申请书格式.docx`（学院发的截图/docx；原件路径随版本变动，找不到就搜 `*入党*`）

## 一、硬性格式要求（学院原文，违反=整份重写）

| # | 要求 | 落笔要点 |
|:-:|------|---------|
| 1 | **吉大黑格稿纸**，全篇同一种纸 | 杜绝其他类型稿纸混用；一份写完不要中途换纸 |
| 2 | 内容**至少九页半** | 见下方字数换算 |
| 3 | **全文不允许任何形式涂改勾抹** | 写错一个字=整页重抄，**多备3-5张纸**，先打草稿再上稿纸 |
| 4 | 第一段**不要写党章** | 开篇直接写"我郑重向党组织提出申请，申请加入中国共产党" |
| 5 | 正文必须出现"**申请入党**"字样 | ❌ 禁止"志愿入党""希望入党"——这是逐字检查项 |
| 6 | 领导人只写**习近平** | 不写毛邓（不是你经历的时代）；**习近平新时代中国特色社会主义思想必写** |
| 7 | 只写**申请时间之前**的事 | 不能把"我已经转了专业"写成既成事实；未来打算要用"我打算/我将" |
| 8 | 中间装订 | 订书器正中装订，**第一页用铅笔**写学号、姓名 |
| 9 | 正文四要素 | ①入党动机 ②本人基本情况+家庭成员+主要社会关系（职业、政治情况）③怎样积极争取入党 ④实事求是 |

## 二、字数换算（用户明确要求"九页半你自己算一下字数"）

| 稿纸规格 | 每页格数 | 九页半 ≈ | 备注 |
|---------|:-------:|:-------:|------|
| 16开黑格稿纸（常见） | 20×20=400 | **3800字** | 含标点，再扣标题+段首缩进空档 |
| 小号稿纸 | 15×20=300 | **2850字** | 版式不确定时问用户每页多少格 |

**做法**：先给 400 格口径的 3800 字版本，并在回复里点明"按实际稿纸微调，多写不删、少写补"。
→ 不要闷头按一个数字写死；规格是唯一未知量，一句话问清比返工便宜。

### 字数必须脚本核（别数标题、别估）
用户要"九页半自己算字数"，**中文字数 ≠ 文件字符数**（markdown 标题/`> 备注`/`---` 分隔线都不该计入）。用 `scripts/count_words.py`（技能自带，复制到文稿目录改 SRC 即可），统计口径：跳过空行/`#`标题/`>`引用/纯符号行，再分别数 `[\u4e00-\u9fff]`（中文）、`[\u3000-\u303f\uff00-\uffef]`（中文标点）、`[A-Za-z0-9]`（英文数字），最后按 300/400 格换算页数，并顺带 assert 格式禁令（不得出现"志愿入党/希望入党"）。改稿后重跑即可复核。

### ⚠️ 交付前先自查篇幅（本会话踩过）
400 格稿纸 9.5 页 = **3800 字**，但"中文字 3630 + 标点 476"这种口径读者会自动读成"远超要求"——用户看到 4191 会以为超了一页。**主动把两个口径都列出来**（纯中文字 vs 含标点），并明确"标点占格、都在预算内"。宁可一次把账算清，也别等用户来质疑。

**报页数要报"正文总字符 ÷ 每页格数"**，别报"中文字÷格数"（标点也占格，中文字口径会低估页数）。且**只给一张表**：`400格 → 9.96 页`，别同时列 2600/2850/3000/3400/3800 一堆换算——用户要的是结论不是计算过程。
本次实测配比：中文字 3481 + 标点 426 + 英文数字 36 = 3984 字符 ≈ 400 格 × 9.96 页（正文小标题"一、二、三"不占额外格，正好卡 9 页半）。**留提前量是故意的**——稿纸规格未确认时，多写易删、少写难补。

## 二·五、⚠️ 长稿必查「前后重复」（用户会直接指出）

**用户说"你那个前后有重复内容啊"是必然事件**，长文书一次成稿极难避开。定稿前**主动跑查重**，别等被抓。

用 `scripts/check_dup.py`（技能自带）：8 字滑窗找跨段落重复片段，自动合并成最长片段只报一次。改稿后重跑，有输出就是没清干净。

本会话实测的**高频重复源**（写长稿时直接规避）：

| 重复对 | 原因 | 处置 |
|---|---|---|
| 开篇自我介绍 ↔ "二、基本情况" | 开头一句"我叫X…父亲…母亲…社会关系"把基本情况整节预支了 | **开篇只写姓名/学院/专业/学号班级/团员**，家庭与社会关系全部留给第二节 |
| 父母教养同义表述 | 开篇"父母靠双手劳动，教我做人要实在" ↔ 第二节"父母是劳动吃饭的人，教我做人要正、做事要实" | 删开篇那半句，只留第二节（那里本来就该展开） |
| 身边党员事例 | 动机节"父亲的党员师傅、母亲单位老党员" ↔ 第五条纪律"父母的单位里都有党员，常说…" | 删后者。**同一素材全篇只能用一次** |
| 身份信息复述 | "2026年9月3日到校报到"在两节各出现一次 | 第二节例证处已无需重复，删 |

**判断标准：同一素材在一处已"展开+带细节"，其他位置必须让位，不能复述。**

**⚠️ 但有两类"重复"必须保留，别手贱删**：
1. **首尾呼应的"申请加入中国共产党"**——格式死规定正文必须出现"申请入党"字样，开篇 + 结尾各一次是**规范写法**（范文皆如此），不是缺陷
2. **必要复现**：学院专业名、课程名、"《习近平谈治国理政》和党的二十大报告"、"已修课程首次考核全部合格"等政策条款原文——政审老师看到前后一致反而加分

这两类要在查重脚本里加白名单（`WHITELIST` / `IGNORE_PAIRS`），否则脚本永远报红、用户会觉得没改干净。

## 三·五、借范文但必须"换肉"（用户会要求"结合网上优秀模板"）

用户说"你去结合一些网上的优秀模板看看"时的正确做法：**只借结构骨架，肉全换成本人真事**。

**先查范文，再列"范文踩了哪些雷"**——网上流传的入党申请书写法大量违反学院格式：

| 范文常见写法 | 学院要求 | 判定 |
|---|---|---|
| 第一段"拥护党的纲领，遵守党的章程…" | 第一段不写党章 | ❌ |
| "我**志愿**加入中国共产党" | 只能写"**申请**入党" | ❌ |
| 只写毛/邓/三个代表/科学发展观 | 必须写到习近平 | ❌ |
| 大段复述党史、三中全会 | 要写本人情况、家庭、社会关系 | ⚠️ 空壳 |

→ 复盘这个对照表给用户，比直接说"我参考了范文"有说服力（用户要的是质量，不是过程）。

**范文里"有人味儿"的四种写法值得抄**（这次都补进去了）：
1. 动机落在**具体的人**身上（父亲单位的党员师傅、母亲单位半夜去修水管的老党员），而不是只讲宏大叙事
2. 写出**认知过程**（初中为"进步"写思想汇报 → 高中觉得政治离我远 → 因身边人作弊想明白），证明不是一时冲动
3. **具体到可查的小事**（军训时帮点名、搬水、陪中暑同学去医务室），比"积极参加集体活动"强十倍
4. 承认差距时给**可验证的笨办法**（每月把思想汇报翻出来对账），别空喊"我会改进"

**写"怎样争取入党"要焊上用户的真实主线**：转专业=学校统一组织集中考核、已修课程首考全合格、接收学院笔试面试；并承认后面要啃理论力学/材料力学/机械原理，已在提前补物理数学——**这句是全篇最亮的**，老师能看出规划不是嘴上说。（已核 `政策文件\吉林大学_本科学生转专业工作管理办法(2025).md` 第六条，引用口径不会错。）

## 三、写作结构（3800字版实测配比，可直接复用）

| 段落 | 内容 | 字数 |
|------|------|:----:|
| 开篇 | 明确提出申请 + 本人简介（姓名/籍贯/学院专业/学号栏/团员/家庭） | ~250 |
| 一、入党动机 | 历史课本→疫情/脱贫攻坚亲见→专业与国家需要挂钩→理论（治国理政/二十大） | ~1100 |
| 二、基本情况 | 成长环境 + 父母职业政治面貌 + 主要社会关系清白声明 + 爱好特长 | ~700 |
| 三、怎样争取入党 | 分5条：①学业 ②思想组织（读原著+季度思想汇报+党校）③班集体做事 ④个人规划放进国家需要 ⑤纪律底线 | ~1400 |
| 结尾 | 承认不足 + 请组织考验 + 落款 | ~350 |

**最有力的写法**：把入党动机**焊在用户的真实主线上**——智能网联汽车/新能源、被卡脖子的核心技术、"关键核心技术是要不来买不来讨不来的"。比空谈信仰强，且老师能看出是本人写的。

## 四、必留填空位（交付时必须单列一张表提醒用户手填）

| 位置 | 内容 | 提醒 |
|------|------|------|
| 姓名下方 | 学号、班级 | 也是封面铅笔项 |
| 家庭成员/社会关系 | 姓名、职业、政治面貌 | **实事求是**，父母是群众就写群众，**绝不编党员** |
| 具体事迹处 | 军训期间干了啥、高中担任过什么 | 没有就改成"主动帮同学搬行李、整理宿舍卫生"，别硬编 |

## 五、同类文书的复用（省得每次重写一遍）

思想汇报 / 转正申请 / 自传 **共用上面全部 party-house rules**（措辞禁令、领导人、不写未来既成事实、涂改零容忍）：

- **思想汇报**：按季度写，每篇锚定 1-2 件本季度真实经历（学了什么课、看了什么新闻、班集体里做了什么），别写成月度总结
- **转正申请**：重点写预备期内"做了什么"对照"入党时承诺什么"，逐条兑现
- **自传**：基本情况一节直接扩写，按时间线（小学→中学→大学）串，社会关系仍然是必填项

## 六、交付习惯

- 用户偏好**可直接抄写的完整正文** + **末尾一张"必须手填"对照表**，不要只给提纲
- 正文不要用 markdown 标题语法污染（`#`/`**` 在稿纸上没意义），用自然段 + 段首缩进意识
- 交付后主动说一句「要不要导成 Word 对照稿」——**然后直接导，别只问**（用户是行动导向）。用 `scripts/gen_docx.py`：宋体小四、1.5 倍行距、首行缩进 2 字符、`w:eastAsia` 必须单独设（否则中文按默认字体渲染）
- 交付时**附一份改了什么/删了什么的对照表**（本次=4 处删除逐条列出），用户要的是「确认改到位」，不是「我改好了」
- 脚本三件套（`count_words.py` / `check_dup.py` / `gen_docx.py`）技能自带，复制到文稿目录改 SRC 即可；改稿后重跑复核

### ⚠️ 导出 Word 时的两个坑
1. **PermissionError [Errno 13]**：目标 docx 正被 Word 打开 → 覆盖失败。**别 kill WINWORD**（用户可能正开着别的文档），改输出名 `_v2.docx` 并在回复里明确「旧文件删掉别抄错」。
2. **改完稿必须重跑 `gen_docx.py`**——只改 md 不重生成，用户拿到的是旧内容；重跑后核对打印出的页数与回复里报的一致。
