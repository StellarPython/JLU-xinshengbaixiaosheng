## 硬指标

| 项目 | 内容 |
|------|------|
| 推免硕士占全日制硕士计划 | **≤50%**（统考名额有保障）|
| 直博名额 | ≤本单位博士招生总数 **30%**（参照2026年数）|
| 复试成绩 | 满分100，**60分合格**，不合格不录取 |
| 面试时长 | 每生 **≥20分钟** |
| 复试小组 | **≥5人**，均副高及以上职称 |
| 面试规则 | **三随机**（考生次序/专家组/试题）+ 全程录音录像 |
| 材料审核组 | 每组 **≥3人**独立打分；**材料审核成绩不得作为唯一录取依据** |
| 录取排序 | 按复试成绩由高到低择优 |
| 政审 | 思想政治素质和品德考核 = **录取首要依据** |
| 跨学科 | 加试成绩不计入复试成绩，但不合格不录取 |

## 报考条件（推免硕士）
①拥护党的领导、遵纪守法、品德良好 ②具推免资格的优秀应届本科毕业生 ③学术兴趣浓厚、专业素养好、创新能力强 ④无作弊、无学术不端 ⑤体检合格
（直博生额外：**≥2名教授/相当职称专家书面推荐**）

## 各学院可自设更高门槛
学校允许各单位额外提出 **学科专业、本科学习成绩排名、外语水平、学术成果** 要求 → 具体看目标学院实施细则（**每年9月16日前**官网公布）

## 工作日程（每年固定）
| 时间 | 事项 |
|------|------|
| **9/15前** | 各招生单位报送实施细则（备案）|
| **9/16前** | 各单位官网**公布实施细则** ← 查细则盯这天 |
| **10/15前** | 复试 + 公示拟录取 + 系统「待录取确认」 |
| **10/20左右** | 学校统一公示（公示7天）；单位内部公示3天 |

## 对用户（2026级 → 目标车辆工程）的意义
1. **GPA 一石二鸟**：转专业看 GPA（≥3.0）、推免看平均学分绩点，是同一指标 → 大一就抓
2. 推免≤50% → 保研竞争激烈但有统考兜底；想保研需专业前列（通常前10-20%，看学院细则）
3. 材料审核看 **科研+竞赛+实践** → 大二起积累（吉速车队/大创/学科竞赛/论文）
4. **思政素质是首要依据** → 入党、学生工作、志愿服务要正经做
5. **外语听说必考** → 英语B级，大一下尽早过四级
6. 面试≥20分钟+三随机 → 靠平时积累不靠突击
