## 四、组织结构

```
吉林大学吉速方程式车队
├── 技术组
│   ├── 底盘：悬架组 / 转向组 / 传动组 / 制动组
│   ├── 发动机组
│   ├── 单体壳组
│   └── 车身（空气动力）组
├── 运营部
│   ├── 新媒体组
│   └── 营销组
└── 车手组
```

成员**全部为吉林大学在读学生**（本硕），配置**对标职业车队**，由指导老师/队长/经理带领。
**技术组选择**：底盘（悬架/转向/传动/制动）与车辆工程专业课直接对应；
单体壳/车身空动偏材料与流体力学。

⭐ **商业口子**：FSC 静态 325 分里**商业报告 75 + 成本与制造分析 100 = 175 分是商科分**
→ 车队**不只招工科生**，营销组/成本组/商业报告组都要人。**技术基础暂时不够时，
从商业报告/成本分析切入是真实可行路径，且分值不低**。

## 六、FSC 赛事（口径已更新为官网数据）

- **国际**：Formula SAE，1978 开办，每年 **15 国、20 余场**，数百支全球高校车队
- **中国**：中国汽车工程学会 **2010 牵头创办**，已办**十六届**（截至 2025）；
  系列赛 = **FSCC（燃油）+ FSEC（电动）+ FSAC（无人驾驶）+ BSC（巴哈）**
- **规模（2026 赛季官网实时）**：**FSCC 139 校 / FSEC 102 校 / FSAC 39 校 / BSC 79 校**
- **地位**：全国高校影响力最大最专业的汽车技术平台；**汽车企业最认可的人才选拔及储备平台**
- 2025 延期：FSEC & FSAC 改至 **2025-11-18~23**，合肥包河区骆岗公园

### ⭐ FSC vs RoboMaster 对比（用户决策用）

| 维度 | **FSC（方程式）** | **RoboMaster** |
|---|---|---|
| 载体 | **一台车** | **一队机器人（7-8 台）** |
| 对抗 | **计分制**（各自跑） | **实时对抗**（同场打基地） |
| 静态分 | **325 分**（设计/成本/商业） | 文档评审，**不计比赛分** |
| 对口专业 | **车辆工程/汽车工程/机械** | 自动化/电子/计算机/AI |
| 校区 | **南岭（同校区）** | 南湖（跨校区） |
| 本质 | 工程项目管理 + 赛车 | 竞技体育 + 机器人 |

→ **对"转车辆工程"，FSC 对口度远高于 RM** —— FSC 考的就是用户将来要学的专业课
（汽车构造/汽车理论/底盘设计/空气动力学）。

## 八、抓取路径备忘

1. **中文长尾实体检索**：Bing 加引号锁实体 —— `"吉林大学" 方程式赛车队 招新`
   → 0 命中变 6700 条。裸词会被"吉林"劫持成吉林省（含 Bing RSS 端点，同样劫持）。
2. **真实链接必须从搜索结果取**：`#b_results a[href^="http"]`。
   ⚠️ 新闻站 URL 是随机数字（`/info/1211/59952.htm`），**猜必 404 或返 200 空壳
   （`<title>搜索</title>`）**，本次猜 URL 白跑两轮。
3. **官网正文可 curl**：jluracing.com 是 WordPress，正文在服务端 HTML（`grab_site.py`）。
4. **吉大新闻中心 / 汽车学院官网正文是 JS 渲染**：curl 只得导航，
   但 **`<title>` 服务端渲染**，标题常含核心事实。要正文走浏览器。
5. **百度百科 403**（换 UA 无效）；**搜狗微信搜索已封**（跳 antispider 验证页）。
6. **B站空间投稿列表接口需 wbi 签名**：`/x/space/wbi/arc/search` 未登录返回
   `-403 访问权限不足`；裸接口 `/x/space/arc/search` 返回 412。
   → **改走浏览器**；但 `/x/web-interface/view?bvid=` 可用，能拿 owner/staff/pubdate。
   视频页底部会列出**全部关联车队账号**（5 支队的名字就在那儿）。
7. **微信公众号无法爬**（无公开 API + 搜狗入口被封）→ 让用户自己在微信里搜关注。
8. ⚠️ **实锤：本会话第一次猜的新闻 URL 全是编的**（`cnjiwang/202609/1449598.html` 等），
   抓回来 7 字或 0 字。**任何 URL 必须来自搜索结果/页面 DOM，不能凭 ID 规律推断**。
